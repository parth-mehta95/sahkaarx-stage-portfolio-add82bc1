# Practice Virtual Environments

## Task Brief
Set up a virtual environment for the data analysis project.

## Scenario
As a data scientist, you need to isolate project dependencies to avoid conflicts. Create and activate a virtual environment for your data analysis pipeline.

## Deliverables
- Functional virtual environment

## Success Criteria
- Virtual environment is created and activated.
- Project dependencies are installed within the environment.
- Code runs correctly within the virtual environment.
- Virtual Environments: Virtual environment created successfully.
- Virtual Environments: Project dependencies installed within the environment.
- Virtual Environments: Environment activated and used for project execution.
