# Practice Version Control: Repository Setup & Basic Commands

## Task Brief
Initialize a Git repository for your data analysis project and make an initial commit.

## Scenario
As a data scientist, you need to track changes to your project. Initialize a Git repository and commit your initial files.

## Deliverables
- Functional Git repository

## Success Criteria
- Repository initialized successfully
- Initial commit created
- Project files tracked
- Repository Setup: Initialized a Git repository
- Basic Commands: Committed initial project files
