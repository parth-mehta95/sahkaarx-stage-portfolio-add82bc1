# Practice Version Control: Commits and Branching

## Task Brief
Create a new branch for a data cleaning feature and commit changes.

## Scenario
You are tasked with implementing a data cleaning feature in the existing data analysis pipeline. Create a new branch, make the necessary changes, and commit them with descriptive messages.

## Deliverables
- Updated GitHub repository

## Success Criteria
- Data cleaning feature implemented on a separate branch.
- Commit messages are clear and concise.
- Branch is properly named.
- Commits: Commit messages clearly describe changes.
- Branching: New branch created for feature development.
